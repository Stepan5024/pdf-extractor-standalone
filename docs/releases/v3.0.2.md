# v3.0.2: unnamed PDF fonts

The extractor treated every font name as non-null when detecting bold text.
Type 3 fonts can omit `/Name`; both `extract` and `combine` then failed with
`Cannot invoke "String.contains(java.lang.CharSequence)" because "fontName" is null`.

Unknown font names now keep the ordinary text style. Text decoding and the
PDF's original fonts are preserved. PDFBox retains responsibility for rendering
font substitution, including its bundled last-resort Liberation Sans font.
This change does not manufacture missing Unicode mappings.

## Regression evidence

- A synthetic, saved-and-reloaded Type 3 PDF without `/Name` reproduces the
  original failure through both CLI commands. Baseline: 6 tests, 2 failures,
  0 errors, 0 skipped; both failures contain the exact reported exception.
- The same test passes after the fix: 6 tests, 0 failures, 0 errors, 0 skipped.
- Standalone `-Pfat-jar verify`: 11 tests pass, including the existing JPEG2000
  rendering regression. Java and POM formatting checks pass.
- The owning `adapstory-cli` implementation has the same guard and five passing
  real-PDF font regression cases; its formatting checks pass.
- The packaged JAR passes `scripts/smoke-test.sh` under Java 17: two input PDFs,
  including an unnamed font in a nested directory, retain their text through
  `combine` and `split`.

## Reproduction and release gate

```bash
mvn -Pfat-jar verify
bash scripts/smoke-test.sh "$PWD/target/pdf-extractor-standalone-3.0.2.jar"
```

Build with JDK 25; run the resulting Java 17 bytecode with Java 17+.
The `Verify Linux release` workflow builds and tests on Ubuntu, reruns tests
under Java 17, then runs the smoke check against both the Linux-built JAR and
the exact downloadable JAR in `dist/`. Publish the release only after that
workflow succeeds for the release source commit. The release notes link its run.

The failing user PDF was not provided. Regression evidence uses a minimal PDF
with the same missing-name condition; it does not establish Unicode recovery
for every symbol in the original document.
